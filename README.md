# Rest Agent Portable

Портативное Windows-приложение для тестирования REST API. Интерфейс на русском языке: коллекции слева, редактор запроса сверху, ответ снизу. Работает без установки и прав администратора.

Как получить готовый EXE после изменения исходников: [пошаговая инструкция по сборке](BUILD.md).

## Запуск

Готовая portable-сборка: [RestAgentPortable-Windows.zip](https://github.com/starlife2018/RestAgentPortable/releases/latest/download/RestAgentPortable-Windows.zip). Распакуйте архив в доступную для записи папку и запустите EXE.

Откройте `RestAgentPortable.exe`. Требуется Windows 10/11 с .NET Framework 4.7.2 или новее. Файл `RestAgentPortable.exe.config` держите рядом с EXE. Исходники для запуска не нужны.

Для переноса скопируйте EXE, его `.config` и папку `data` в доступную для записи папку, например на USB-накопитель. В `Program Files` данные могут не сохраняться из-за прав доступа.

## Панель коллекций и темы

В самом верху левой панели находятся логотип и название **REST AGENT**. Под ними расположены **История** и **Коллекция** с векторными иконками и подчёркиванием активной вкладки. Поиск под вкладками фильтрует историю и дерево по имени, методу и URL. В подвале находятся **Импорт**, **Экспорт**, **Запрос**, **Каталог**, **Настройки**: используются иконки документов, каталогов, стрелок и шестерёнки. Меню строки открывается вертикальным троеточием или правой кнопкой мыши. Копирование, перемещение, переименование, удаление и каталоги назначения имеют векторные иконки.

В **Настройки → Оформление** доступны темы **Светлая**, **Графит**, **Океан**, **Лес**. Цвета меняются сразу для предварительного просмотра: фон окна, панели/меню, поля/редактор кода, основной и вторичный текст, акцент, разделители и цвета левой панели. Подсветка кода адаптируется к тёмному фону. Цвета HTTP-статусов сохраняют своё значение.

Чтобы создать свою тему, выберите готовую, нажмите **Создать свою**, задайте имя и цвета в формате **#RRGGBB**, затем нажмите **Применить**. **Сохранить тему** добавляет текущие цвета в список редактируемых тем; все изменения списка окончательно сохраняются кнопкой **Применить**. Свою тему можно изменить или удалить кнопкой с корзиной. Готовые шаблоны сохраняются неизменными. **Отмена** и закрытие настроек отменяют предпросмотр и несохранённые изменения. Вкладка **Общие** содержит настройку автозапуска.

Выбранная тема и свои палитры хранятся в `data/themes.json`, при обновлении сохраняется `themes.json.bak`. После перезапуска восстанавливаются активная тема и список своих тем. Коллекции и параметры запросов при смене оформления не меняются.

## Работа с запросами

1. Выберите HTTP-метод, укажите полный URL и таймаут в секундах (1–600).
2. Вкладки идут в порядке **Заголовки → Параметры → Тело запроса**. В заголовках **＋ Из каталога** открывает поиск по имени и описанию: доступны частые заголовки, весь реестр и имена из ваших запросов. Выберите имя, введите значение или воспользуйтесь подсказками и нажмите **Добавить**. **Своя строка** добавляет пустую строку для ручного ввода. Кнопка **⋯** рядом с именем открывает каталог для существующей строки; **×** удаляет её. Значение сохраняется при смене имени. Флажок включает строку в запрос одним нажатием.

Во вкладке **Параметры** доступны такие же аккуратные строки, поиск через **＋ Из списка** / **⋯**, ручной ввод через **Своя строка**, удаление через **×** и включение одним нажатием. **Копировать URL** копирует полный адрес с активными параметрами. Строка адреса и таблица синхронизируются в обе стороны: можно менять строки или вставить готовый URL с параметрами. Выключенные строки не отправляются. Даты вводятся обычным текстом, например `2026-10-09 00:00:00`; пробелы, двоеточия, знаки +, &, %, Unicode и другие специальные символы кодируются автоматически. При повторном сохранении/открытии параметры не дублируются. Если одно имя уже есть в URL и в таблице, значение таблицы имеет приоритет; намеренно повторяющиеся строки, например `tag[]`, поддерживаются. Рядом с ответом отображается адрес последнего отправленного запроса.
3. Для POST/PUT/PATCH заполните тело и задайте соответствующий `Content-Type`, например `application/json`. Тело передаётся в UTF-8. GET и HEAD отправляются без тела.
4. Нажмите **Отправить** или `Ctrl+Enter`. Отображаются реальный HTTP-статус, время, размер декодированного текста в UTF-8, заголовки и тело ответа. JSON и XML автоматически форматируются; другие ответы показаны как текст с подходящей подсветкой. **Отмена** прерывает запрос.
5. **Сохранить** или `Ctrl+S` сохраняет запрос в коллекцию. При первом сохранении укажите имя и выберите папку; повторное сохранение обновляет запрос без диалога. Новый запрос и новая папка создаются внутри выбранной папки. **Все запросы** — корень дерева.

В дереве HTTP-методы выделены цветом, длинные имена сокращаются с подсказкой. **F2** или **Переименовать** включает редактирование имени прямо в строке: Enter сохраняет, Esc отменяет. Меню **⋯** у строки и правая кнопка мыши позволяют создать копию запроса, переместить элемент в папку или удалить его. Удаление требует подтверждения; папка удаляется вместе с содержимым. Папку нельзя переместить внутрь себя или её потомков. Поиск работает по имени, HTTP-методу и URL, сохраняет родительские папки найденных запросов; поиск имени папки показывает её содержимое. Кнопка × очищает поиск. Выделение и свёрнутые папки сохраняются при обновлении дерева в течение сеанса.

Левую панель можно расширять или сужать перетаскиванием разделителя. Кнопка **☰** в шапке или **Ctrl+B** скрывает и показывает панель. Ширина и видимость сохраняются в `data/view-settings.json`; при узком окне ширина ограничивается, чтобы редактор запроса оставался удобным.

Название текущего запроса меняется нажатием на название или **✎** рядом с ним: **Enter** сохраняет, **Esc** отменяет, переход в другое поле сохраняет непустое имя. У сохранённого запроса имя сразу обновляется в дереве и файле коллекции. Несохранённые изменения тела, URL и заголовков при этом остаются в редакторе. Для нового запроса имя будет использовано при сохранении.

Запросы и папки можно **перетаскивать мышью в папку или «Все запросы»**. Место назначения выделяется рамкой; закрытая папка раскрывается при наведении, у краёв дерева включается прокрутка. Если отпустить элемент над запросом, он переместится в папку этого запроса. Внутри папок элементы отображаются по имени. Перемещение в саму папку или её потомка блокируется. Во время редактирования имени **Delete** удаляет текст; вне поля переименования Delete вызывает подтверждение удаления элемента. Контекстное меню и вложенный список папок оформлены в стиле приложения.

История хранит последние 100 полученных HTTP-ответов как снимки запросов; выбор записи открывает новый запрос для редактирования.

Каталог заголовков содержит локальный снимок полного [реестра HTTP-полей IANA](https://www.iana.org/assignments/http-fields/) от 2026-10-09 и распространённые пользовательские поля. Он работает без Интернета. Реестр включает также поля ответов и устаревшие поля: выбирайте подходящие для вашего API. У query-параметров нет единого универсального реестра: предлагается 48 распространённых имён с описаниями и имена из ваших сохранённых запросов. Свои можно вводить свободно; точные названия и допустимые значения определяет конкретный API.

GET и HEAD отправляются без тела, даже если указан `Content-Type` или другой заголовок содержимого. Выбранные заголовки сохраняются. Для этих методов `Content-Length` допускается только со значением 0; `Transfer-Encoding` и `Expect: 100-continue` нужно убрать. Заполненное поле тела для GET/HEAD вызывает понятное сообщение до отправки. Для POST/PUT/PATCH/DELETE можно отправлять тело или оставить его пустым.

Тело запроса и ответа показывается в редакторе с номерами строк и подсветкой **JSON, XML, HTML, JavaScript, CSS и SQL**. В режиме **Авто** формат определяется по Content-Type и содержимому. Список над текстом позволяет выбрать формат вручную или отключить подсветку («Текст»). Выбор подсветки не меняет HTTP-заголовки и отправляемый текст. **Форматировать** работает для JSON и XML; форматирование запроса можно отменить Ctrl+Z. Числа JSON сохраняют исходную запись, включая точность. Unicode-последовательности внутри JSON-строк (например, `\u041d`) отображаются обычными буквами при автоматическом форматировании ответа и нажатии **Форматировать**. Поддерживаются русский, украинский и эмодзи. Копирование и сохранение ответа включают читаемые символы в UTF-8; кавычки, управляющие символы и буквальный текст вида `\\u041d` сохраняют корректное экранирование.

Полоса статуса зелёная для 2xx, жёлтая для 3xx, красная для 4xx/5xx и ошибок подключения/таймаута. Во время отправки и после отмены используется нейтральный цвет.

В JSON рядом с открывающими скобками объектов и массивов отображаются стрелки **▸ / ▾**. Нажатие сворачивает или раскрывает отдельную группу; свёрнутая строка показывает первые поля и значения серым текстом. Длинное содержимое сокращается многоточием. Работает и в теле запроса, и в ответе; пустые объекты и массивы остаются обычным текстом. В XML кнопки сворачивания находятся рядом с номерами строк.

Кнопка **▤ Группы** над ответом оставляет корень и массивы раскрытыми, а объекты и вложенные массивы, которые являются элементами массивов, сворачивает в отдельные строки. Например, в `orders` каждый заказ показывается строкой с `id`, датами и другими первыми полями, как в дереве JSON. Кнопка доступна, когда в JSON есть такие элементы. Стрелкой можно раскрыть один заказ, сохранив остальные свёрнутыми. Двойное нажатие на краткое содержимое также раскрывает группу.

**Свернуть всё / Развернуть всё** управляют всеми блоками ответа, **В начало / В конец** прокручивают текст. Копирование и сохранение включают полный текст, даже если блоки свёрнуты. Для документов больше 2 МБ сворачивание отключается, чтобы не сканировать весь текст; подсветка, просмотр, копирование и сохранение остаются доступны. HTML подсвечивается; сворачивание работает для корректного XML-совместимого HTML.

## Данные и настройки

Коллекции и история сохраняются рядом с EXE в `data/workspace.json`. При перезаписи создаётся `workspace.json.bak` с предыдущей версией. Запись атомарная. Если файл повреждён, приложение сохраняет его и блокирует перезапись: восстановите резервную копию и перезапустите приложение.

**Экспорт** сохраняет текущие коллекции и историю в JSON. **Импорт** добавляет папки и сохранённые запросы из этого формата, создавая новые идентификаторы; локальная история остаётся прежней. Несохранённый редактор не включается в экспорт. Файлы Postman/HAR пока не поддерживаются.

**Настройки → Запускать при входе в Windows** записывает путь к EXE в пользовательский ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Изменение применяется только по кнопке **Применить** и не требует администратора. После переноса EXE включите настройку заново; перед удалением приложения отключите её.

Токены и заголовки хранятся в открытом виде в коллекциях, истории, экспортах и резервных копиях. Приложение не содержит токенов со скриншота. Проверка TLS-сертификатов включена. HTTP-перенаправления показываются как ответы 3xx: приложение не пересылает авторизацию на другой адрес автоматически. Cookies не сохраняются между запросами. Максимальный буфер ответа — 16 МиБ; бинарные ответы отображаются как текст. Файлы, multipart, OAuth-потоки, переменные окружения и WebSocket не реализованы.

## Разработка

Проект написан на C# и WPF. Для сборки не нужны .NET SDK и восстановление NuGet: редактор AvalonEdit и его лицензия включены в каталог `vendor`. Разметка, иконка и библиотека редактора встроены в EXE. Подход WPF описан в [документации Microsoft](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/).

Из PowerShell в папке проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Скрипт использует компилятор установленного .NET Framework, упаковывает сгенерированную `App.png` в `App.ico` в семи размерах и собирает EXE. `App.cs` содержит приложение, `Main.xaml` — интерфейс, `HeaderCatalog.cs` — каталог и окно выбора, `HttpFieldRegistry.csv` — встроенный снимок реестра, `BodylessTransport.cs` — отправку GET/HEAD без тела с сохранением заголовков содержимого, `SelfTest.cs` — самотест, `CodeEditor.cs` и `Json.xshd` — подсветка и сворачивание кода. Описание генерации иконки находится в `ICON.md`. Не запускайте сборку поверх работающего EXE; для отдельного выходного файла доступен параметр `-OutputName`.

Проверки:

```powershell
$testProcess = Start-Process .\RestAgentPortable.exe -ArgumentList '--self-test' -WindowStyle Hidden -Wait -PassThru
Get-Content .\test-results.txt
$testProcess.ExitCode
```

Самотест проверяет JSON, вложенные коллекции, резервные копии, циклы папок, кодирование URL, редакторы заголовков и параметров, загрузку XAML и HTTP GET/POST с ответами 200/401 на временном localhost-сервере, отмену, таймаут и восстановление кнопок после запроса. Для дерева проверяются выделение, несохранённый редактор, переименование с Enter/Esc, перемещение, защита от циклов, копирование, поиск, свёрнутые папки, рекурсивное удаление и сохранение без повторного диалога. Окно первого сохранения проверяется с выбором папки и оформлением полей. Рабочая коллекция не изменяется. Код завершения 0 означает успех. `preview.png` и `save-preview.png` создаются отрисовкой интерфейса; ручная работа мышью и реальными API требует отдельной проверки.

Для каталога заголовков проверяются полный список без дублей, поиск, пользовательские имена, подсказки значений, сохранение значения при смене имени, проверка имени, добавление, редактирование, отмена и удаление строки. Проверяются порядок вкладок и семь размеров встроенной иконки. `header-picker-preview.png` показывает окно каталога.

HTTP-проверки включают регрессию GET/HEAD с пустым телом и включёнными `Content-Type`/`Content-Language`: локальный сервер проверяет фактически полученные заголовки и отсутствие тела. Также проверяются GET с ответом 401, пустой POST, DELETE с телом, отмена и таймаут.

Для параметров проверяются синхронизация URL/таблицы, замена совпадающих полей без дублирования, выключенные строки, повторяющиеся имена, массивы, даты, Unicode и специальные символы, сохранение/загрузка, поиск и редактирование через список, удаление строки и компактные кнопки на ширине 1000/1280/1920. Локальный HTTP-сервер проверяет точную строку запроса с `createdAt`, `createdTo`, `uzdStatus` и массивами. `parameters-preview.png` показывает вкладку параметров, `parameter-picker-preview.png` — окно выбора.

## Редактор кода

Самотест группировок проверяет стрелки в строках, независимое раскрытие заказов, краткое содержимое, корневой и вложенные массивы, пустые и однострочные значения, экранированные скобки в строках, сохранение пробелов и чисел, ограничение длинных превью, полный источник для копирования/сохранения и отключение группировок для больших документов. `json-groups-preview.png` показывает свёрнутые заказы, `json-group-expanded-preview.png` — раскрытие одного заказа.

Используется [AvalonEdit 6.3.1.120](https://www.nuget.org/packages/AvalonEdit/6.3.1.120) под лицензией MIT. DLL для .NET Framework находится в `vendor/AvalonEdit/lib/net462/`, исходный NuGet-пакет сохранён в `vendor/`. При сборке DLL и лицензия встраиваются в EXE: отдельная DLL рядом с приложением не требуется, сборка работает без Интернета. Текст лицензии — `vendor/AvalonEdit-LICENSE.txt`.

Самотест дополнительно проверяет цвета JSON-токенов, смену Content-Type, JSON/XML-блоки, скобки внутри строк, сохранность полного текста при сворачивании, отмену форматирования, повреждённый XML, большие ответы и панель кнопок при ширине 1000/1280/1920. Локальный HTTP-сервер проверяет цветные статусы 200/201/302/401/500 и JSON/XML/HTML. `code-preview.png`, `code-collapsed-preview.png`, `code-error-preview.png` показывают обычный, свёрнутый и ошибочный ответы.

Проверки навигации охватывают ширину и скрытие панели, восстановление настроек, переименование в шапке, Enter/Esc, Delete внутри имени запроса и папки, события перетаскивания (запрос/папка/корень/защита от циклов), отклонение посторонних данных и оформление меню. `navigation-preview.png`, `sidebar-hidden-preview.png`, `context-menu-preview.png` — изображения нового интерфейса. Код навигации находится в `Navigation.cs`.

Самотест Unicode проверяет приведённый пользователем русско-украинский ответ, получение экранированного JSON по HTTP, отображение и источник текста для копирования/сохранения, суррогатные пары эмодзи, слеши, кавычки, управляющие символы, точность чисел и повторное форматирование. `unicode-response-preview.png` показывает результат.

Проверки оформления: вкладки с иконками и повторное нажатие на активную вкладку, поиск истории, пять действий подвала на минимальной ширине, векторные иконки меню/подменю, четыре темы и контраст подсветки кода на тёмном фоне, проверка HEX, создание/сохранение/восстановление/удаление своей темы, отмена предпросмотра и сохранность коллекции, текста, позиции курсора и свёрнутых блоков.
